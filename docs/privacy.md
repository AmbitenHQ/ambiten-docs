The operators of those applications are responsible for their own privacy information.

## 3. Hosting through GitHub Pages

The documentation is published as a static website through **GitHub Pages**, a service provided by GitHub. GitHub receives technical information when browsers request pages and associated website resources.

GitHub expressly states that the **IP address of each visitor to a GitHub Pages site is logged and stored for security purposes**, whether or not that visitor is signed in to GitHub. Other technical information may be processed in connection with serving and protecting the website, depending on GitHub's infrastructure and practices.

The documentation is hosted this way so visitors can access technical content and the website can operate reliably and securely. To the extent that processing is carried out under our responsibility, we rely on **Article 6(1)(f) GDPR** (legitimate interests in providing and securing the documentation website), where applicable. GitHub also describes processing it carries out under its own responsibilities in its privacy statement.

For details about GitHub Pages and GitHub's handling of personal data, see:

- [GitHub Pages: What is GitHub Pages?](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages)
- [GitHub General Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)

**Retention:** GitHub controls the storage and retention of its GitHub Pages security logs. An exact log-retention period has not been established by Abinod in this notice. GitHub's published privacy information explains its retention practices and the criteria it applies.

## 4. International processing

Although Abinod operates from Germany, **GitHub Pages hosting does not establish that all website-request data stays in Germany or the European Union**. GitHub describes processing in different locations, including the United States and other countries, and discusses international transfer arrangements in its privacy statement.

Applicable safeguards and transfer mechanisms must be assessed according to the services and arrangements actually used. You can read GitHub's explanation of international transfers in its [General Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

## 5. Domain registration and DNS

The domain used for the documentation is registered through **Porkbun**. Domain registration and domain-management services are separate from the hosting of website pages, which takes place through GitHub Pages.

Depending on the live DNS configuration, technical DNS queries may be handled by the authoritative DNS service configured for the domain. This notice does not assume that Porkbun necessarily receives each visitor's website request merely because it is the registrar.

For information about Porkbun's own processing, see its [Privacy Policy](https://porkbun.com/legal/agreement/privacy_policy).

## 6. Browser storage and optional website features

The documentation uses **VitePress**, which can store interface preferences in the browser, including the appearance (light or dark theme), depending on the configuration. VitePress's default theme uses local storage to restore a visitor's appearance preference. Browser storage is not the same thing as a user account, but storing or reading information on a device must still be considered under the applicable rules, including **Section 25 TDDDG**.

Search behavior depends on the configured search provider. An in-browser local search can work differently from a hosted third-party search service. The live VitePress configuration, external assets, analytics, and any optional storage must be verified before publishing this notice as a complete description of deployed website behavior.

## 7. External links and resources

The documentation may link to GitHub repositories, npm packages, product websites, and other external technical resources. When you follow an external link, the destination service may process personal data under its own privacy notice.

If third-party scripts, fonts, embedded media, or hosted search tools are loaded directly within the documentation website, these may also lead to requests to their providers and must be disclosed according to the deployed configuration.

Correspondence is retained as necessary for the enquiry and applicable legal obligations. Additional information about Abinod's business email handling appears in the [Abinod Privacy Policy](https://www.abinod.com/privacy/).

Subject to the relevant legal conditions, you may have rights of access, correction, erasure, restriction of processing, data portability, and objection. Where processing relies on consent, you may withdraw that consent without affecting earlier lawful processing.
